# Executive Career Hub V15 — Dynamic Career Highlights

Career Highlights are no longer hard-coded.

For every application, the app:
1. Reads the target role and full job description.
2. Scores only verified candidate achievements against JD terminology.
3. Selects and orders the five most relevant highlights.
4. Uses the same dynamic highlights in Premium PDF, Premium DOCX, and ATS output.
5. Never invents a new number or achievement.

Examples:
- Experiential / events JD prioritizes event attendance, end-to-end ownership, budget, team scale and flagship exhibitions.
- CRM / lifecycle JD prioritizes 35% engagement growth, 3,000+ SQLs, customer journey, regional expertise and leadership.
- Partnerships JD prioritizes bank and insurance partnerships, commercial pipeline, budget governance and stakeholder leadership.
